# Sprocket

Classroom 3D-print helper for Bambu Lab printers.

**Version:** 1.3.0  
**Live app:** open `Sprocket.html` or `index.html` in Chrome. Data stays in the browser (`localStorage` key `printkit-v2`).

## What is in this build
- Convert (mm/in, temp, flow, strength, class clock)
- Stock (spools, supplies, AMS map, dry flags)
- Timers (print / cool / glue / dry + custom h+m)
- Help (official Bambu wiki links)
- More (queue, fail log, printer care, backup/restore)

No unofficial Studio impersonation. No live printer control in Phase 1.
